# Z 合成工令取消與結案的操作限制

此文件僅供離線檢索測試，不代表任何公司的現行工令規範。取消流程與結案流程是不同操作，值班人員要先確認目前畫面的狀態。這段前言刻意包含查詢的各個中文字，但沒有描述取消結案這個完整動作。測試資料需要保留前後段落的距離，才能驗證是否真的取得後面的作業限制。操作人員會在紀錄上填寫確認人、確認時間、工令號碼與狀態來源；這些欄位不能代替真正的作業規則。排程畫面、結案畫面與取消畫面都可能顯示相似的文字，單字重疊不能當成流程一致的證據。再次確認工令狀態後，才可依下方明確規則執行。

## 實際限制

合成工令取消結案後，必須由主管覆核原結案紀錄，才能重新排程；不得直接沿用舊的核准狀態。
